# من يحق له استدعاء كل مسار API (docs/api-access.md)

> **المرحلة 3.** الافتراضي **حماية كل شيء**: كل مسار API يتطلب جلسة موقّعة (كوكي
> `fqmg_session` الصادر من `POST /api/auth/login`)، ولا يقبل الهوية من الجسم أو ترويسات
> يتحكم بها العميل. `src/proxy.ts` بوابة خارجية سريعة، وكل معالج يعيد التحقق بنفسه عبر
> `authenticateApiRequest()` — المعالج هو الحد الفعلي. الاستثناء الوحيد: `AUTH_ENABLED=0`
> (مخرج تطوير موثّق، يلغي المصادقة والتفويض وحد المعدل معًا ويُحذَّر عند تفعيله).

| المسار | الطريقة | المصادقة | حد المعدل (لكل مستخدم) | كلفة الاستدعاء | تفويض إضافي |
| --- | --- | --- | --- | --- | --- |
| `/api/auth/login` | POST | عام (يُصدر الجلسة) | `auth-login` — **لكل IP** (5/5د) | لا شيء (فحص بيانات محلي) | — |
| `/api/auth/logout` | POST | عام (يمسح الكوكي) | `ip-global` عبر proxy | لا شيء | — |
| `/api/generate` | POST | مطلوبة | `generate` 10/د | **مدفوع**: مزود النماذج (بث + كائنات تحقق) | — |
| `/api/plan` | POST | مطلوبة | `plan` 30/د | لا شيء (مخطط محلي) | — |
| `/api/voice/providers` | GET | مطلوبة | `voice-providers` 30/د | قد يستدعي مخزون المزود (كاش 30ث) | — |
| `/api/voice/synthesize` | POST | مطلوبة | `voice-synthesize` 10/د | **مدفوع**: مزود الصوت | الملف الناتج ملك لمن طلبه |
| `/api/voice/audio/{id}` | GET | مطلوبة | `voice-audio` 60/د | قراءة ملف محلي | **403** لغير المالك أو مرجع بلا مالك مسجّل (fail-closed) |

> `/api/lambda/progress` (تركيب `DynamicComp` القديم عبر `inputProps`) حُذفا
> مع الشيفرة الميتة للتركيب القديم. عرض Lambda يتم حصريًا عبر محركات العرض
> (src/render/lambda) في حلقة QA أو عبر `npm run deploy:lambda` للبنية التحتية.

حدود إضافية: `ip-global` (120/د لكل IP) في `src/proxy.ts` قبل فحص الجلسة، لتخفيف الضرب
العام قبل أي معالجة.

## نموذج الهوية

1. **المصدر:** `FQMG_USERS="username:scrypt$salt$hash,..."` في البيئة — ولّد السجل بـ
   `npm run auth:hash -- "<password>"`. لا مستخدمون = لا أحد يدخل (وليس فتح الأبواب).
2. **الجلسة:** كوكي `fqmg_session` = `base64url(payload).HMAC-SHA256` بمفتاح `AUTH_SECRET`
   (≥32 حرفًا)، صلاحية 12 ساعة، `HttpOnly; SameSite=Lax; Secure` في الإنتاج. تسجيل الدخول
   يفشل برسالة عامة واحدة (لا تعداد مستخدمين)، ومحاولاته محدودة لكل IP.
3. **الإبطال:** إزالة المستخدم من `FQMG_USERS` تلغي كوكيه فورًا (فحص الملكية عند كل طلب).
4. **فشل مغلق:** `AUTH_SECRET` مفقود/قصير والفرض مفعّل ⇒ كل شيء 401 (وليس تجاوزًا ضمنيًا)؛
   مرجع صوت بلا مالك مسجّل ⇒ 403؛ مرجع لا يعرفه المخزن ⇒ رفض.
5. **كل مستخدم ولله ميزانية:** سقف `AGENT_USER_DAILY_BUDGET_USD` (افتراضي = السقف اليومي
   العام) في `src/agent/budget.ts` — تجاوزه يفشل مغلقًا ولا يستهلك حصة مستخدم آخر،
   والسقف اليومي العام يبقى صلبًا على الجميع.

## حدود معلومة (تنقل إلى المرحلة 5)

- حد المعدل يبقى **process-local** (عدادات لكل نسخة). الميزانية وسجل المهام أصبحا
  قابلين للمشاركة منذ المرحلة 5: `FQMG_REDIS_URL` يفعّل ذرّية Lua عبر النسخ
  (فشل مغلق عند تعذر المخزن)، وكاش الصوت يشارك عبر `VOICE_CACHE_STORE=s3`
  مع `FQMG_S3_*` — انظر D-024 و`.env.example`.
- لا صفحة تسجيل دخول في الواجهة بعد (المسار API جاهز) — مؤجل إلى المرحلة 8 مع E2E.
- `x-forwarded-for` يُستخدم كمفتاح IP: خلف وكيل عكس موثوق هو الصحيح؛ مكشوفًا يمكن
  تزييفه لتدوير عداد IP — حدود «لكل مستخدم» (كوكي موقّع) هي الحد القوي.
