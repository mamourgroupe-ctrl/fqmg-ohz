# Phase 1 — حدود المعمارية

> **ملاحظة الدمج (2026-10-12):** نُقل كود `fqmg-ohz-next/` إلى جذر المستودع، فصارت المسارات المذكورة هنا
> (`src/ai`, `src/motion`, `src/render`, `src/voice`, `src/remotion/entry.tsx`) مسارات جذرية مباشرة،
> ومسار المخطط `POST /api/generate` (داخل المشروع الفرعي) أصبح `POST /api/plan`. لم تُعدَّل الحدود
> الأمنية ولا القرارات المعمارية الموصوفة أدناه.

## مسار البيانات الحالي

`Prompt + خيارات آمنة → DirectorProvider → خطة محلية قابلة للتكرار → Scene Planner → MotionSpecificationSchema → Remotion composition blueprint`

- عقد `DirectorProvider` لا يعتمد على OpenAI. الموفر المنفذ حاليًا هو `local-rules` فقط، ولا يرسل بيانات إلى الخارج.
- `MotionSpecification` هي بيانات Zod فقط؛ لا تحتوي على كود تنفيذي ولا تُمرر إلى `eval`/`new Function`.
- سجل أبعاد النسب موجود في `src/render/presets/aspect-ratios.ts` وهو المصدر الوحيد للأبعاد في هذه المرحلة.
- `RemotionAdapter` يتحقق من المخطط ويترجم المواصفة إلى خصائص تركيب Remotion. مكوّن `MotionComposition` يعرض النصوص والصور/الفيديو والأشكال المعرفة كطبقات آمنة؛ لا يدّعي أن هذا تكامل عرض SaaS أو أن ملف MP4 أُنتج.
- `RenderJobSchema` يفرض `output` وتقدم 100% للحالة الناجحة. المسار المخصص لإنهاء المهمة يتحقق من وجود ملف MP4/WebM فعلي ويستدعي `ffprobe` لإثبات وجود stream فيديو وأبعاد وFPS ومدة؛ يفشل مغلقًا إذا لم يتوفر `ffprobe`. لا يوجد عامل Queue أو تخزين دائم بعد.
- واجهة الويب تستدعي API نسبيًا (`/api/generate`)؛ لا يوجد اتصال من المتصفح إلى localhost أو خدمة خارجية.

## الحدود الأمنية

- طلبات API تتحقق من الحجم والبنية والأنواع قبل التخطيط.
- مصادر الأصول تقبل HTTPS أو مسارات `/assets/` و`/uploads/` أو معرفات `asset://` فقط؛ تُرفض `javascript:`, `data:`, `file:` والمسارات المتراجعة.
- الإشارات إلى أصل الصورة/الفيديو/الصوت تُراجع مقابل قائمة الأصول وأنواعها.
- متغيرات `.env.example` أسماء توضيحية فقط. لا توجد مفاتيح مطلوبة أو موفر خارجي مفعّل.

## غير المنفذ عمدًا في هذه المرحلة

Voice Router/TTS وCache، إنشاء نص صوتي فعلي، تحليل صور/فيديو/Pinterest، Brand Profile كامل، subtitles مزامنة صوتية، Adobe adapters التنفيذية، Render queue/worker/تخزين/قياس استخدام، مصادقة/اشتراكات، وQC وإصلاح تلقائي. تبقى بنية هذه الأنظمة لمرحلاتها المحددة ولا تُعرض كميزات مكتملة.
